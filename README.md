# RETUTAL.SYS

Personal portfolio of Brix Bryan A. Retutal, a third-year Computer Engineering student at Cagayan State University.

Static HTML, CSS, and vanilla JavaScript. No dependencies, build step, or backend are required. Serve the project root with a static HTTP server for local previews.

## Vercel

Import this repository with the **Other** framework preset and the repository root as the project directory. The checked-in configuration uses no build command and serves the root directory.

Local verification reports and screenshots remain in `artifacts/`, excluded from Git and CLI deployment. No credentials or environment variables are needed by the site.

Canonical and Open Graph URL metadata should be added after the production URL is confirmed. A social preview image has not been selected.
